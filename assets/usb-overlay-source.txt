Both sizes keep the stock artwork within each panel's available USB overlay
area; R1 and R3 Pro II use the unscaled 300 x 300 original.

The original image is from the stock R1 firmware root at
/usr/resource/litegui/theme2/usb/usb.png. The player loads this path for its
full-screen USB DAC mode overlay. Firmware cleanup pruned the stock file
because no tracked asset declared the path, so the packagers now install the
board-sized, hash-pinned original or deterministic resize after cleanup.
