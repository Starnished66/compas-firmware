# Stock UI images that nothing in the shipped system loads. repack_upt.sh -> clean_os.py
# deletes every path below from /usr/resource/litegui after the tracked assets are copied
# (a missing path is skipped; a path that is also tracked under assets/ is an error).
#
# Format: one path per line relative to /usr/resource/litegui.
#   */<dir>/<file>     theme1 and theme2
#   theme2/<dir>/<file>  theme2 only (theme1 files of that name are live: a theme with
#                        icon_root=theme1 resolves them directly and bypasses the Breeze swap)
#
# Rule used: a file stays if compas_player/compas_loader can name it (any asset_path()
# literal or format, the gui_themes.c legacy inventory, layout_images[], titlebar and
# breeze_row maps), or a published plugin/theme references it (compas-plugins), or it is
# the "_s" pressed sibling of one of those.  Everything below is neither.
# Many names below are also in gui_themes.c s_legacy_asset_inventory (the stock names the old
# Themes plugin copied). Removing the stock file is safe for theme2: those icons are only drawn
# through titlebar_breeze_icon()/breeze_row_icon() (decorate_category_row, power_hub_card,
# resolve_file_row_icon), which never consult the override folder, so a leftover legacy override
# copy is never shown either way. theme1 copies stay: an icon_root=theme1 theme draws them.
